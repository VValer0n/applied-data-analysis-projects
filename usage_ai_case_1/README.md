Учебный проект по курсу «Прикладной анализ данных», посвящённый сегментации персонала на основе вовлечённости в использование инструментов искусственного интеллекта и уровня автоматизации рабочих задач. В качестве исходных данных выступает синтетический датасет на 20 000 записей с 16 признаками, описывающими демографические, профессиональные и операционные характеристики сотрудников (возраст, образование, отрасль, доля рутинных задач, уровень принятия ИИ, количество используемых ИИ-инструментов, риск увольнения и др.). Цель исследования — выявить устойчивые паттерны поведения сотрудников, оценить их подверженность автоматизации и сформулировать рекомендации по адаптации кадровой стратегии (upskilling/reskilling) для минимизации рисков увольнений.

В работе реализован полный аналитический пайплайн. На этапе разведочного анализа (EDA) распределения категориальных признаков проверены критерием хи-квадрат Пирсона, а непрерывных — критерием Колмогорова-Смирнова; построены корреляционные матрицы, включая phik для оценки нелинейных связей между смешанными типами данных. В рамках Feature Engineering созданы интегральные метрики AI_Engagement и Automation_Exposure_Score. Предобработка включает стандартизацию числовых признаков (StandardScaler), порядковое кодирование (OrdinalEncoder) для признаков с естественным порядком и One-Hot Encoding для номинальных. Для кластеризации сравнены три алгоритма — KMeans, DBSCAN и AgglomerativeClustering — с подбором гиперпараметров и оценкой качества по трём метрикам: Silhouette Score, Davies-Bouldin Index и Calinski-Harabasz Index. Кластеры дополнительно визуализированы в двумерном пространстве методом PCA и профилированы по исходным признакам.

Лучшей моделью признана агломеративная кластеризация с линковкой ward и двумя кластерами (Silhouette Score = 0.4849, Calinski-Harabasz = 7005.14). Анализ профилей кластеров позволил выделить две устойчивые группы сотрудников: «группа высокого риска автоматизации» — специалисты с высокой долей рутинных задач (>70%), активным использованием ИИ-инструментов и позициями Entry/Mid уровня, чья взаимозаменяемость создаёт непосредственный риск увольнения; и «группа экспертных знаний» — сотрудники, опирающиеся на уникальный опыт, креативность и сложные человеческие взаимодействия, чьи функции в краткосрочной перспективе сложнее автоматизировать. На основе этих инсайтов сформулированы практические рекомендации: перераспределить ресурсы на переобучение первого кластера со смещением фокуса с рутинных задач на аналитические и управленческие, а для второго — внедрить ИИ-ассистенты как конкурентное преимущество, повышающее производительность.
Стек: Python 3.13, Pandas, NumPy, SciPy, Scikit-learn (StandardScaler, OrdinalEncoder, KMeans, DBSCAN, AgglomerativeClustering, PCA), Seaborn, Matplotlib, phik, Jupyter Notebook.
